# 🃏 斗地主 AI 训练营

一个帮助**零基础小白从第一局开始学会斗地主**的网页游戏：完整真实的斗地主对局流程，每次轮到你出牌时，**AI 教练**会给出出牌建议和通俗的理由讲解；对手 BOT 分三档难度。纯前端、零依赖、零构建。

## 🚀 运行方式

**方式一（最简单）**：直接双击打开 `index.html` 即可玩（已验证 file:// 协议可用）。

**方式二（本地服务器）**：
```bash
# 任意一种
npx http-server -p 8642        # 然后访问 http://127.0.0.1:8642
python -m http.server 8642
```

**运行测试**（需要 Node.js）：
```bash
node test/sim.js    # 56 项逻辑单元测试 + 210 局 BOT 自动对局仿真
```

## 🎮 玩法入口

- 主页选难度 → 开始游戏；**手机请横屏游玩**（竖屏会提示旋转，可选仍要竖屏）
- 桌面端 AI 教练停靠右侧；移动端点右下 🤖 悬浮球展开方案抽屉，点方案立即打出
- 游戏内右上角可随时开关 **AI 教练**、**记牌器**、**音效**，可随时打开教程
- 支持的牌型：单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子 / 连对 / 飞机（带单、带对）/ 四带二 / 四带两对 / 炸弹 / 王炸

## 🧠 AI 教练的实现

全部为**客户端启发式算法**（不调用任何外部 API，离线可玩）：

1. **牌型识别**（`analyze`）→ **合法走法枚举**（`legalMoves`）
2. **手牌拆解**：把手牌拆成尽量少的"手数"（飞机 → 连对 → 顺子 → 三张/对/单），作为局面评估的核心指标
3. **决策**：能一手出完直接赢 → 只剩两手先出大的 → 否则出"剩余手数最少 + 牌力最小"的走法；跟牌时最便宜的牌接上、炸弹看时机、农民给队友让牌、对手报单时大牌压制
4. 教练在决策之上输出**中文讲解**（为什么出 / 为什么不出 / 局面提醒），并对你的每手牌与 AI 建议做对比点评

## ⚙️ 技术说明

- 原生 HTML/CSS/JS，无框架、无构建、无外部依赖；所有模块挂载在全局命名空间 `DD`
- 逻辑层不接触 DOM，因此可在 Node 中做大规模仿真（本项目跑了 210 局 ×3 难度全部正常收敛）
- 页面内置测试钩子（不影响正常游戏）：
  - `index.html?autotest=game` 打开即自动开局；`?autotest=autoplay` 全自动演示整局（人类座位由 AI 代打）
  - `&side=1` 强制展开 AI 教练侧栏；`?debug=1` 输出布局诊断；`?debug=2` 自动验证"方案两段式点击"交互规范
  - JS 运行错误会显示在页面左下角红色浮层，便于自动化截图发现问题
