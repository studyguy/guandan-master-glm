# 斗地主 AI 训练营 · 架构文档（ARCHITECTURE.md）

> 本文档是项目的"架构 Prompt"，任何会话在继续开发前必须先读本文件，遵守已锁定的架构。

## 1. 项目背景
做一个网页版斗地主新手训练营：真实完整的斗地主对局流程 + 每次轮到玩家出牌时 AI 教练给出出牌建议和理由，帮助零基础玩家从第一局开始学会斗地主。

## 2. 目标用户
完全不会斗地主的小白玩家（需要教程、纠错提示、随时可看的 AI 辅导）。

## 3. 核心需求
1. 完整真实的斗地主流程：54 张牌发牌 → 叫分抢地主 → 亮底牌 → 轮流出牌 → 胜负结算（含炸弹翻倍、春天）
2. AI 教练：轮到玩家时给出"建议出什么 + 为什么"，支持一键按建议出牌；对玩家的每次出牌给出点评
3. 出牌校验：选牌实时显示牌型，非法牌型/压不过时用通俗中文解释原因（教学式纠错）
4. 不同难度的 BOT 对手：入门（随机型）/ 进阶（贪心型）/ 高手（策略型：拆牌优化、农民配合、压制残局）
5. AI 教练侧边栏：局势概览 + 中文分析 + 可点选方案列表（DD.buildPlans 生成，点方案直接打出），桌面停靠 / 移动横屏抽屉
6. 学习辅助：内置新手教程、记牌器、积分累计（localStorage）；移动端横屏适配（动态扇形手牌、安全区、触控优化）

## 4. 架构设定
- 产品形态：Web 网页（单页应用：主页 / 对局 / 教程弹层）；**桌面与横屏手机双形态，移动端以横屏为主体验**
- 架构模式：分层模块化（逻辑层 → 状态机层 → 表现层），无框架；表现层引用 :root 设计令牌（色彩/字号/间距/圆角/阴影/卡牌尺寸）
- 运行环境：纯本地，双击 index.html 即可运行（file:// 协议兼容，不用 ES Module）

## 5. 技术约束
- 语言：原生 HTML5 + CSS3 + JavaScript（ES2017+，无 TypeScript、无框架、无构建工具、零依赖）
- 模块组织：多 `<script>` 顺序加载，全部挂载到全局命名空间 `DD`（window.DD）
- 存储：localStorage（键 `dd_trainer_settings`、`dd_trainer_stats`）
- AI：全部客户端启发式算法（牌型识别 → 合法走法枚举 → 手牌拆解最少手数 → 策略决策），不调用任何外部 API
- 兼容目标：Chrome / Edge 现代版本，桌面优先

## 6. 非功能需求
- 逻辑层（cards/combos/movegen/ai/advisor/game）不得接触 DOM，保证可在 Node 中做仿真测试
- BOT 对局必须保证收敛（先手必有牌可出 → 对局必然结束）
- 卡牌全部用 CSS 绘制，不依赖任何图片资源；音效由 WebAudio 代码实时合成（js/sfx.js），无音频文件、可开关

## 7. 实施计划（模块依赖顺序）
```
项目总目标
├── A. 牌与牌型核心（cards.js → combos.js）       ← 一切的地基
├── B. 走法生成（movegen.js，依赖 A）
├── C. AI 策略（ai.js：拆解/叫分/三档 BOT，依赖 A/B）
├── D. AI 教练（advisor.js：建议 + 中文讲解，依赖 C）
├── E. 对局状态机（game.js：发牌/叫分/出牌/结算，事件驱动，依赖 A–C）
├── F. 音效（sfx.js：WebAudio 合成，可开关，独立于逻辑层）
├── G. 表现层（ui.js/app.js/style.css/index.html，依赖 E 的事件）
└── H. 测试（test/sim.js：单元测试 + 200 局 BOT 自动对局仿真）
```

## 8. 输出要求
每个模块：代码 + 简要说明；逻辑层必须有仿真测试覆盖后才接入表现层。

## 9. 验收标准
- 打开 index.html 能完成 发牌→叫分→出牌→结算→下一局 全流程，无 JS 报错
- AI 教练在每次玩家回合给出具体建议与理由；非法出牌有通俗解释
- 三档难度 BOT 行为有可感知差异；200 局自动对局仿真全部正常结束
- 牌型识别覆盖全部 14 种牌型且边界正确（2 和王不能进顺子/连对/飞机等）

## 10. 限制条件（不要做什么）
- 不引入 npm/构建工具/CDN 依赖，不使用 ES Module（保证 file:// 直接打开）
- 不做联网对战、不做后端、不接外部大模型 API（教练为内置启发式 AI）
- 不引入图片/音频素材文件（音效仅允许 WebAudio 代码合成），不做移动端深度适配（桌面优先、基本自适应即可）
- 不过度设计：不做房间系统/皮肤/战绩图表等超出核心需求的功能
